Пинг по миру

Логика повторяет ip.net.coffee/ping: пинг запускает их сервер (сеть узлов check-host), по 4 ICMP-пакета с каждого узла, браузер забирает результаты. Лимит оригинала — 10 проверок одного адреса в сутки. В поле сразу подставляется твой IP выхода к Cloudflare. Российский узел у них один — Москва; других узлов в РФ их сервер не принимает, а сам check-host.net прямые запросы из браузера не пускает.
