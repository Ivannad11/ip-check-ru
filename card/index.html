Чей IP увидят на моём сайте — мой или посетителя?

Посетителя. Код вставки ссылается на card.net.coffee/v1/card.svg без IP: их сервер смотрит, с какого адреса пришёл запрос картинки, и рисует карточку для него (проверено: отвечает редиректом на ?ip=<адрес запросившего>). Превью здесь собирается с твоим IP — так же, как у оригинала.

Чей это сервер?

Картинку рисует сервер оригинала — card.net.coffee (Net.Coffee), у нас своего генератора нет. Здесь — только конструктор на русском: стили, стикеры, превью и готовый код. Данные об IP (страна, сеть, Trust) — из их базы, текст на карточке английский.

Какой IP попадёт на карточку, если у меня VPN с раздельной маршрутизацией?

Тот, через который браузер ходит на card.net.coffee (это зарубежный сайт на Cloudflare, обычно — выход VPN). Российский IP туда не попадёт.

Регистрация, ключи, оплата?

Не нужны. Китайские стикеры (来了老弟 — «Заходи, братан», 绝密 — «Совершенно секретно», 好评+1 — «Лайк», 三网优化 — «Оптимизация для трёх операторов КНР», CN2 / 9929 / CMIN2 — магистрали китайских операторов) оставлены как в оригинале.

Конструктор повторяет card.net.coffee/ip. Картинки: card.net.coffee/v1/card.svg (Net.Coffee). IP для превью — /cdn-cgi/trace того же сервера.
