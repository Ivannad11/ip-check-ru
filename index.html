СайтIPГде
Логика проверок повторяет ip.net.coffee. Китайский выход — iP138.com и IP.cn, российский — STUN Яндекса и Sipnet (российские адреса идут мимо VPN при раздельной маршрутизации). IP к сайтам — их /cdn-cgi/trace (Cloudflare), заголовки CDN NetEase и ByteDance, STUN для российских сервисов. Гео и тип IP — открытый API ip.net.coffee.
